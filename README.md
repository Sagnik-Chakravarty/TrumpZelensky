# Trump–Zelensky Political Discourse Analysis

This repository documents a computational social science project analyzing online and media discourse around the Trump–Zelensky interaction and its broader political framing. The project is positioned as a public-discourse measurement workflow using text-as-data methods, sentiment/stance analysis, and narrative framing documentation.

## Repository Description

Computational social science project analyzing Trump–Zelensky political discourse using text-as-data workflows, sentiment/stance measurement, narrative framing, and reproducible documentation.

## Project Motivation

High-salience political events are interpreted differently across media outlets, platforms, and partisan communities. These interpretations shape public attention, trust, and policy debate. This project uses the Trump–Zelensky discourse context as a case study for measuring how political narratives form, diffuse, and diverge across public communication environments.

The project is designed as a research portfolio artifact showing how political discourse can be converted into structured, analyzable data while preserving caution about measurement validity, platform bias, and interpretive uncertainty.

## Research Questions

1. How did public discourse frame the Trump–Zelensky interaction across political and media contexts?
2. What dominant narratives, sentiment patterns, and stance categories appear in the discourse?
3. How can text-as-data methods help summarize high-volume political discussion while retaining interpretability?
4. What are the limitations of using digital trace data to infer broader public opinion?

## Methods

The project framework includes:

- data collection from political/news/social-media sources,
- text cleaning and preprocessing,
- keyword and topic filtering,
- sentiment analysis,
- stance or framing classification,
- narrative-category summaries,
- platform/source comparisons,
- visualization and reporting.

## Limitations

This repository should be interpreted as a political discourse analysis project, not as a population-representative measure of public opinion. Digital trace data and media data reflect platform selection, source selection, engagement dynamics, and framing effects. Results should therefore be interpreted as evidence about observed discourse rather than direct evidence about the broader public.
