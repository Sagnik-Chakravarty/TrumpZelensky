# Reports

This directory contains readable report files for the Trump–Zelensky / Ukraine discourse stance-classification project.

## Files

- `assignment3_stance_classification_report.md`: Markdown version of the Assignment 3 report comparing traditional machine learning and LLM approaches for Reddit stance classification.

## Report Summary

The report compares SVM, Decision Tree, and Gemma-based LLM classification for a four-class stance detection task:

- Favor
- Oppose
- Neutral
- Irrelevant

The main finding is that SVM achieved the strongest overall performance, but all approaches struggled with class imbalance and minority stance categories.
