# Limitations and Ethics

## Digital Trace Limitations

Political discourse data from news and social platforms should not be interpreted as representative public opinion. These data are shaped by platform demographics, engagement incentives, posting behavior, moderation, source selection, and event timing.

## Political Interpretation

High-salience political events often involve competing interpretations. Sentiment, stance, and framing labels simplify complex discourse and should be used as interpretive aids rather than definitive judgments.

## Source Bias

Media outlets and social platforms differ in audience, editorial selection, ideological orientation, and coverage priorities. Comparisons across sources should be interpreted with these differences in mind.

## Privacy and Data Use

Only public or appropriately shareable data should be included in this repository. If social media data are used, public outputs should avoid exposing personally identifying information or unnecessary user-level details.

## Responsible Reporting

Recommended reporting practices:

- clearly distinguish observed discourse from population opinion,
- document data sources and keyword filters,
- report time windows and inclusion criteria,
- avoid overclaiming causal effects,
- acknowledge uncertainty in automated sentiment or stance labels,
- provide transparent documentation of classification methods.
