# Project Overview

## Trump–Zelensky Political Discourse Analysis

This project analyzes public discourse and political framing around the Trump–Zelensky interaction. It is designed as a computational social science case study using text-as-data methods to organize, summarize, and interpret political narratives.

## Research Motivation

Political events involving international leaders often generate competing narratives across media, political actors, and online communities. These narratives can shape public attention, issue interpretation, and policy debate. This project examines how a high-salience political event can be studied using structured discourse analysis.

## Research Questions

1. What dominant frames appeared in discourse about the Trump–Zelensky interaction?
2. How did sentiment and stance vary across sources or communities?
3. Which keywords, topics, or narrative categories were most central to the discussion?
4. What are the limitations of using online discourse and media data to infer broader public opinion?

## Intended Contribution

The project demonstrates a workflow for converting messy political discourse into structured research outputs. It is relevant to computational social science, political communication, survey-adjacent public opinion research, and NLP-based discourse analysis.

## Main Outputs

- Project documentation and analysis plan.
- Text-as-data workflow documentation.
- Political framing and sentiment analysis structure.
- Limitations and ethics notes for political digital trace analysis.
