# Data

This directory is reserved for raw and processed political discourse data.

Suggested structure:

```text
data/
  raw/
  processed/
```

Do not commit restricted, private, or non-shareable data. If social media data are used, avoid publishing unnecessary user-level information.

Recommended metadata fields:

- source,
- platform,
- date/time,
- title/headline,
- text,
- URL,
- keyword,
- sentiment label or score,
- stance label,
- frame label.
