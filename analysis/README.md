# Analysis

This directory is reserved for scripts, notebooks, or Quarto reports used to analyze Trump–Zelensky political discourse.

Suggested analysis files:

```text
01_data_cleaning.qmd
02_sentiment_stance_analysis.qmd
03_framing_analysis.qmd
04_visualization.qmd
```

Potential analysis outputs include:

- cleaned discourse dataset,
- keyword and topic summaries,
- sentiment distributions,
- stance classification tables,
- frame-frequency tables,
- source/platform comparisons,
- time-series visualizations.
